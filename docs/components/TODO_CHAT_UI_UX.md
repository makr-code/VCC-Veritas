### Canvas für Rounded Corners

```python
def create_rounded_rectangle(canvas, x1, y1, x2, y2, radius=15, **kwargs):
    """Erstellt abgerundetes Rechteck für Bubble"""
    points = [
        x1+radius, y1,
        x2-radius, y1,
        x2, y1,
        x2, y1+radius,
        # ... weitere Punkte
    ]
    return canvas.create_polygon(points, smooth=True, **kwargs)
```
